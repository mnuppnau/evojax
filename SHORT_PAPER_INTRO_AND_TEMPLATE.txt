----------------------------------------------------------------------------
Condensed Introduction (Short-Paper Version)
----------------------------------------------------------------------------

Generative Adversarial Networks (GANs) are difficult to train because adversarial dynamics can lead to instability, mode collapse, and brittle gradients. InfoGAN is attractive in this setting because it encourages latent variables to capture disentangled, human-inspectable structure without supervision. This is especially relevant in healthcare, where synthetic data should be controllable and auditable rather than merely realistic.

In our prior work \cite{}, we replaced generator backpropagation with PGPE, evolving the generator against a moving discriminator objective. While this avoided direct gradient propagation through the generator, it still required evolutionary search over a very large parameter space (more than 500k generator parameters), which often produced partial mode coverage and duplicated latent-code assignments. In the strongest MNIST runs, one class was typically missing and one or more codes collapsed to repeated digits.

In this work, we reduce that search burden with a HyperNetwork. Rather than evolving the full generator directly, PGPE optimizes a compact HyperNetwork that emits the weights of a larger image generator conditioned on latent codes, while the discriminator/Q-network is still trained with backpropagation. This yields a smaller, more structured search space and an architectural prior over generator weights. We present stable baseline results on MNIST and grayscale-converted BloodMNIST, showing improved mode coverage, cleaner code allocation, and more stable late-stage training than direct parameter search. These baselines provide the foundation for our full-paper study, which will add cultural-algorithm guidance and ablation analyses.

2. Method (0.4-0.6 page)
- One short paragraph on the architecture:
  - HyperNetwork emits generator weights
  - PGPE updates HyperNetwork
  - discriminator/Q trained by backprop
- One short paragraph on the evaluation protocol:
  - shared-z groups
  - discrete code variation
  - metrics: `r_sense`, `r_intra`, mode coverage / code allocation
- Draft paragraph:
  We evaluate disentanglement with a shared-z protocol designed to isolate the effect of the discrete code. For each sampled latent group, multiple samples share the same continuous noise vector while only the discrete code is changed, so differences within the group should reflect code-dependent structure rather than random noise. We then measure inter-code separation in the discriminator feature space with `r_sense`, which rewards code centroids that move apart, and within-code variation with `r_intra`, which tracks whether samples assigned to the same code remain coherent without collapsing to a single prototype. In practice, we pair these metrics with direct inspection of fixed image grids and report mode coverage / duplicate-code failures as the main qualitative indicators of controllable generation.
- Include one compact figure if space permits:
  a diagram of HyperNetwork -> Generator, with PGPE and D/Q updates

3. Experimental Setup (0.25-0.4 page)
- Datasets:
  - MNIST: 28x28 grayscale, 10 classes
  - BloodMNIST: grayscale-converted 28x28, 8 classes
- Same baseline used across both datasets
- Keep only the most important training settings
- Do not list every hyperparameter; defer to appendix/full paper if allowed
- Draft paragraph:
  We use the same baseline architecture and training protocol across both datasets, changing only the number of discrete classes. The latent vector contains 62 noise dimensions, a dataset-specific one-hot discrete code (10 for MNIST and 8 for BloodMNIST), and 2 continuous codes. A HyperNetwork generates the weights of the image generator, while PGPE updates the HyperNetwork parameters and the discriminator/Q-network is optimized with backpropagation. All images are generated at 28x28 resolution in grayscale, with BloodMNIST converted from its original color representation to match the baseline pipeline. To focus this short paper on a stable reference system, we disable cultural-algorithm guidance and report the HyperNetwork-PGPE baseline alone; all CA ablations are deferred to the full paper.

- BloodMNIST:

Minimal Storyline For The Short Paper
----------------------------------------------------------------------------

1. Direct evolutionary search over full generator weights is too hard.
2. A HyperNetwork reduces and structures the search space.
3. This produces a much stronger PGPE baseline on MNIST.
4. The same setup transfers to BloodMNIST with partial but meaningful disentanglement.
5. Full CA-guided optimization is the next step, not the main claim of the short paper.
