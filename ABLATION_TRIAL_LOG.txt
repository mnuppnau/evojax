  - D update gate threshold (currently hardcoded at 0.30).
  - Early D-step frequency window (currently 1/3 until 1.5k).

Trial B01e - BloodMNIST control (CA off) with explicit saturation penalty
----------------------------------------------------------------------
Status
- In progress (run observed through ~24k).

Motivation
- B01d improved early image quality but diverged around 3.5k-5k with rising
  adversarial variance and visible image degradation.
- PGPE needs an explicit penalty against saturated/binary shortcut phenotypes.

Code updates
- `evojax/policy/convnet.py`
  - Added per-member `sat_frac = mean(|fake_pixels| > 0.85)` in `forward_fn_gen`.
  - Routed `sat_frac` through `get_actions(...)`.
- `evojax/sim_mgr.py`
  - Propagated `sat_frac` through rollout/eval pipeline and returned it to trainer.
- `evojax/trainer.py`
  - Passed `sat_frac` into `solver_hn.tell(...)`.
  - Added `sat_frac_avg` and `sat_excess_avg` to `metrics.tsv` logging.
  - Added saturation summary logging per interval.
- `evojax/algo/pgpe_ca.py`
  - Added saturation-penalty knobs:
    - `sat_penalty_weight`, `sat_target`,
      `sat_penalty_start_iter`, `sat_penalty_ramp_iters`.
  - Added fitness term:
    - `sat_excess = relu(sat_frac - sat_target)`
    - `sat_pen = clip(sat_excess / (1 - sat_target), 0, 1)`
    - `fitness -= sat_pen * w_sat_t` with linear ramp.
  - Exposed diagnostics: `w_sat`, `sat_target`, `sat_frac_avg`, `sat_excess_avg`.
- `examples/train_bloodmnist.py`
  - Added CLI flags for saturation penalty knobs and passed them to `PGPE_CA`.

Initial defaults
- `sat_penalty_weight=0.12`
- `sat_target=0.10`
- `sat_penalty_start_iter=1500`
- `sat_penalty_ramp_iters=1500`

Run command (B01e)
python examples/train_bloodmnist.py \
  --gpu-id='0,1' \
  --checkpoint-interval=5000 \
  --ca-blend-coeff=0.0

Evaluation target
- Reduce post-3k saturation drift while preserving early B01d image quality.
- Keep `sat_excess_avg` near 0 while maintaining/improving `adv_max`.

Observed snapshot (~24k)
- D/G balance is improved versus earlier collapse runs but still D-leaning.
- `sat_frac_avg` remains high (~0.55-0.70), so current `sat_penalty_weight=0.12`
  is insufficient for strong anti-saturation pressure.
- Persistent edge-line artifact remains visible in generated images.

Trial B01g - Saturation-aware adversarial governor (dynamic adv cap)
----------------------------------------------------------------------
Status
- Ready to run (code updated).

Motivation
- B01f still diverged around ~6k with `sat_frac_avg` drifting toward ~0.9+.
- `w_sat` was already high, but adversarial pressure could still dominate ranking.
- Need to reduce adversarial domination specifically when saturation is elevated.

Code updates
- `evojax/algo/pgpe_ca.py`
  - Added saturation-aware adversarial governor knobs:
    - `adv_sat_trigger` (default `0.20`)
    - `adv_sat_cap_min` (default `0.35`)
    - `adv_sat_strength` (default `0.85`)
  - Added dynamic adversarial rank cap:
    - `adv_rank_shaped = clip(rank_normalize(fitness_adv), -cap, +cap)`
    - `cap` shrinks as mean `sat_excess` rises after sat ramp starts.
  - Added distress suppression:
    - `adv_distress` is scaled by `(1 - adv_sat_govern)` during high saturation.
  - Reused existing sat ramp (`sat_penalty_start_iter`, `sat_penalty_ramp_iters`)
    so governor activates smoothly.
- `examples/train_bloodmnist.py`
  - Added CLI flags for the three governor knobs and wired them into `PGPE_CA`.

Suggested run command (B01g)
python examples/train_bloodmnist.py \
  --gpu-id='0,1' \
  --checkpoint-interval=5000 \

  --sat-penalty-weight=0.25 \
  --adv-sat-trigger=0.20 \

Trial B01j - Decaying D-input noise schedule + `disc_features=16` support
----------------------------------------------------------------------
Status
- Ready to run (code updated).

Motivation
- Recent runs looked strong until ~3k, then degraded; this aligns with
  saturation/governor full-ramp timing and rising D shortcut pressure.
- Add stronger early D-input regularization that decays slowly.

Code updates
- `evojax/trainer.py`
  - Added decaying noise schedule knobs:
    - `disc_input_noise_start`
    - `disc_input_noise_end`
    - `disc_input_noise_decay_iters`
  - Applied schedule to D-step real/fake input noise.
  - Logged `disc_input_noise_std` to `metrics.tsv`.
  - Syncs rollout/eval D-input noise scale each iteration via `SimManager`.
- `evojax/sim_mgr.py`
  - Added `set_disc_noise_scale(...)`.
  - Applies scale to task noise before `policy_net.get_actions(...)` so
  convnet discriminator path sees the same scheduled noise as trainer D-step.
  - Fixed topographic centroid broadcast bug when `n_codes * feature_dim == pop_size`
    (e.g., `8 * 64 == 512` at `disc_features=16`):
    flatten+repeat logic now always treats topographic tensors as a single
    centroid vector per population member, avoiding scalar per-member centroids.
- `evojax/policy/convnet.py`
  - D-input noise path now explicitly consumes externally scheduled noise
    (`fake_data + asarray(noise)`), keeping dtype stable.
- `examples/train_bloodmnist.py`
  - Added CLI flags for decaying D-input noise schedule.
  - Added noise schedule values to startup logging.

Suggested run command (B01j)
python examples/train_bloodmnist.py \
  --gpu-id='0,1' \
  --checkpoint-interval=5000 \
  --ca-blend-coeff=0.0 \
  --disc-features=16 \
  --disc-lr=3e-5 \
  --disc-warmup-freq=1 \
  --disc-warmup-iters=5000 \
  --disc-input-noise-start=0.24 \
  --disc-input-noise-end=0.10 \
  --disc-input-noise-decay-iters=40000 \
  --sat-penalty-weight=0.25 \
  --adv-sat-trigger=0.20 \
  --adv-sat-cap-min=0.35 \
  --adv-sat-strength=0.85

Evaluation target
- Delay or avoid the 3k-4k collapse onset while preserving early image quality.
- Keep `real_fake_loss` occupancy healthier without forcing D inactivity.
