Trial T04 - Route 2: r_shape_div integration
--------------------------------------------------------------------------------
Run ID / Source
- Current active run on updated code.
- Live logs: log/organsmnist/metrics.tsv, log/organsmnist/ks_weights.tsv
- Current image checkpoints: iteration-1000.npy ... iteration-11000.npy

Code changes (Route 2 pivot)
- Added r_shape_div in latent task as conditional diversity proxy:
  Var[f_D(G(z,c)) | c] in discriminator feature space.
- Routed r_shape_div through sim_mgr -> trainer -> solver tell().
- Added fitness term: rank_normalize(r_shape_div) * w_shape.
- Extended Domain KS archive with r_shape_div and 4-axis Pareto:
  [|adv|, |mi|, -shape_div, |entropy|].
- Domain KS stagnation path now selects highest r_shape_div archive member.
- Added CLI knob: --shape-div-weight (default 0.12).

Configuration used
- Same command family as previous run, with Route 2 code now active:
  python examples/train_organsmnist.py --gpu-id='0,1' --checkpoint-interval=5000 \
    --ca-blend-coeff=0.015 --ca-blend-start-iter=4500 --ca-blend-ramp-iters=3000 \
    --ca-blend-rfl-lo=0.43 --ca-blend-rfl-hi=0.56 --shape-div-weight=0.12

Current observations (iter 8000-10500 snapshot)
- adv_max mean: -0.8397
- mi_avg mean: -0.6474
- r_sense mean: 0.0619
- r_intra mean: 0.9144
- r_shape_div mean: 0.1370
- real_fake_loss mean: 0.5022

Image notes (through ~11k)
- D/G balance remains healthy, but repeated shapes within each code are still the dominant visual failure mode.
- Some codes show minor variation, but not enough for strong within-code disentanglement.

Interpretation
- Route 2 plumbing is correct and stable.
- Mean-only r_shape_div appears insufficient to penalize per-code collapse.

Trial T05 - Collapse-sensitive Route 2 refinement (implemented)
--------------------------------------------------------------------------------
Run ID / Source
- Code update only (next run pending on this patch set).
- Modified files:
  evojax/task/latent.py
  evojax/sim_mgr.py
  evojax/trainer.py
  evojax/algo/pgpe_ca.py
  evojax/algo/cultural/knowledge_sources.py
  scripts/compare_metrics_tsv.py

Code changes
- Added `shape_div_min` (worst-code conditional diversity) end-to-end.
- Kept `shape_div_mean` and changed shape reward to collapse-sensitive blend:
  `shape_score = 0.7 * shape_div_min + 0.3 * shape_div_mean`.
- Added shape-div history buffer + slopes in CA (`shape_short`, `shape_med`).
- Made `w_shape` CA-adaptive with strict clamp `[0.02, 0.20]`.
- Added MI guard:
  when `shape_div_min` falls below target, reduce `w_mi` and nudge `w_shape`.
- Extended logs:
  - `metrics.tsv`: now includes `r_shape_div_min_avg`.
  - `ks_weights.tsv`: now includes `shape_short`, `shape_med`,
    `shape_div_min_avg`, `shape_div_score_avg`, and `mi_guard`.

Rationale
- Mean-only conditional diversity allowed partial code collapse to hide in averages.
- This patch promotes worst-code recovery and prevents MI-only prototype shortcuts.

Validation command for T05
- python examples/train_organsmnist.py --gpu-id='0,1' --checkpoint-interval=5000 \
  --ca-blend-coeff=0.015 --ca-blend-start-iter=4500 --ca-blend-ramp-iters=3000 \
  --ca-blend-rfl-lo=0.43 --ca-blend-rfl-hi=0.56 --shape-div-weight=0.12

Success criteria for T05
- Maintain healthy `real_fake_loss` occupancy.
- Improve `r_shape_div_min_avg` without degrading adversarial stability.
- Increase within-code structural variety in 11k panels.
- Avoid MI improvement that coincides with repeated per-code prototypes.

Trial T06 - BloodMNIST Morphology Metrics + Layer-A-Only CA (implemented)
--------------------------------------------------------------------------------
Run ID / Source
- Branch: claude/evolve-infogan-hypernetworks-s3r6d-67132f2-blood
- Status: code update complete, next training run pending.

Configuration intent
- Keep CA conservative (Layer A visibility/logging only).
- Add direct morphology diagnostics and weak fitness shaping.
- Keep changes minimal to avoid destabilizing the D/G game.

Code changes
- Disabled Layer-B scoring influence:
  - `topographic_score(...)` and `domain_score(...)` now ignore spread-slope inputs.
- Added three generated-image morphology metrics:
  - `morph_dark_range`
  - `morph_center_edge_range`
  - `edge_dark_frac`
- Routed metrics end-to-end:
  `convnet.py -> sim_mgr.py -> trainer.py -> pgpe_ca.py`.
- Added weak morphology fitness terms in `pgpe_ca.py`:
  - reward dark-range,
  - reward center-edge-range,
  - penalize excess edge-darkness above target.
- Tightened `r_intra` window in `latent.py` to reduce within-code noise.
- Extended logging:
  - `metrics.tsv`: added morphology averages.
  - `ks_weights.tsv`: added morphology weight columns.
- Fixed rollout initialization robustness:
  - `sim_mgr.py` metric buffers now size by `params_gen.shape[0]` (instead of `self._pop_size//2`).

Rationale
- Real-data analysis showed clear deficits in dark-mass distribution and center-vs-edge structure.
- This patch first improves observability and introduces low-pressure corrections before stronger objective changes.

Expected readout for next run
- `edge_dark_frac_avg` should trend down without forcing adversarial collapse.
- `morph_dark_range_avg` and `morph_center_edge_range_avg` should increase gradually.
- `r_intra` should settle into a tighter band with less fuzzy/smeared output.

Trial T07 - Blur-Based Code Spread (implemented)
--------------------------------------------------------------------------------
Run ID / Source
- Branch: claude/evolve-infogan-hypernetworks-s3r6d-67132f2-blood
- Status: code update complete; next run pending restart.

Code change
- In `evojax/policy/convnet.py`, `code_pixel_div` now uses a 3x3 edge-padded
  average blur of generated images before variance-across-codes is computed.

Rationale
- Prior runs showed that direct pixel-space code spread pressure increased
  blotchy/high-frequency artifacts.
- Blurring shifts the reward toward shape-scale differences and away from
  texture noise shortcuts.

Expectation
- Reduced blotchiness/noise at equal or better code separation.
- Lower within-code variance drift while preserving improved D/G balance.
